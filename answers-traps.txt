 2. Where is the call to function f in the assembly 
 code for main? Where is the call to g? (Hint: the 
 compiler may inline functions.)

There is no call to function f in main's code. Instead
, the return value of f in this case is determined by
main and is directly stored into a1.
The call to g is inlined in f. As line 35-39 of f is
the same as line 20-24 in g. Judging from the memory
addresses, these two sets of instructions actually 
points the same instructions in memory.
